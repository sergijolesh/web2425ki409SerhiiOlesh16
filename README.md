## Task Details
The point of this course is to create a website using web technologies. As a topic I have chosen a desktop wallpapers website. The website should serve as a platform where users can browse, search, and download high-quality wallpapers.
### Features:
- A gallery view displaying available wallpapers.
- Categories and search functionality for better user experience.
- A download button to save wallpapers in different resolutions.
- A settings menu allowing users to configure viewing preferences.

## Technology Stack:
- Frontend: HTML, CSS, JavaScript.
- Backend: Python.
- Data base: MySQL.
